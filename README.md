# Κάλυψη — Σύστημα Διαχείρισης Αδειών Προσωπικού

Web εφαρμογή (λειτουργεί και σε κινητό σαν κανονική σελίδα/PWA) για αιτήσεις αδειών,
εγκρίσεις με έλεγχο ελάχιστου προσωπικού, υπόλοιπα αδειών, και ημερήσια εκτυπώσιμη
κατάσταση προσωπικού.

## Τεχνολογίες
- **Next.js 14** (React, TypeScript) — ένα και μοναδικό project για employee & admin
- **PostgreSQL** μέσω **Prisma ORM**
- **Δικό μας session με JWT** (χωρίς εξωτερικό πάροχο σύνδεσης) — email + κωδικός

## 1. Τοπική εγκατάσταση

```bash
npm install
cp .env.example .env
```

Άνοιξε το `.env` και βάλε:
- `DATABASE_URL` — σύνδεση σε PostgreSQL (βλέπε §3 για δωρεάν επιλογές)
- `JWT_SECRET` — οποιοδήποτε μεγάλο τυχαίο string (π.χ. `openssl rand -hex 32`)

Δημιουργία πινάκων + demo δεδομένα:

```bash
npm run db:migrate
npm run db:seed
```

Εκκίνηση:

```bash
npm run dev
```

Άνοιξε http://localhost:3000 — demo λογαριασμοί (κωδικός για όλους: `password123`):
- Διαχειριστής: `admin@company.gr`
- Υπάλληλος: `eleni@company.gr` (και άλλοι 5, δες `prisma/seed.ts`)

## 2. Πώς δουλεύει

| Λειτουργία | Πού |
|---|---|
| Είσοδος χρηστών | `/login` |
| Ημερολόγιο/υπόλοιπο/αίτηση άδειας | `/dashboard` (υπάλληλος) |
| Εκκρεμείς αιτήσεις + έλεγχος ελάχιστου προσωπικού | `/admin` → «Εκκρεμείς» |
| Ημερήσια εκτυπώσιμη κατάσταση | `/admin` → «Ημερήσια κατάσταση» → κουμπί Εκτύπωση |
| Πίστωση/αφαίρεση χρόνου άδειας | `/admin` → «Υπόλοιπα» |
| Καθορισμός ελάχιστου προσωπικού | `/admin` → «Εκκρεμείς» (πάνω αριστερά) |

Κάθε έγκριση αίτησης αφαιρεί αυτόματα τις ώρες από το υπόλοιπο του υπαλλήλου μέσα σε
database transaction (`src/app/api/requests/[id]/decision/route.ts`), ώστε να μην
υπάρχει περίπτωση ασυνέπειας.

## 3. Δωρεάν βάση δεδομένων (χωρίς δικό σου server)

Οποιοδήποτε από αυτά δίνει δωρεάν PostgreSQL με ένα `DATABASE_URL`:
- **Supabase** — supabase.com → New Project → Settings → Database → Connection string
- **Neon** — neon.tech → δημιουργεί URL αυτόματα
- **Railway** — railway.app → Provision PostgreSQL

Κάνε paste το connection string στο `.env` και τρέξε `npm run db:migrate`.

## 4. Deployment (Vercel — δωρεάν για μικρή κλίμακα)

1. Ανέβασε τον φάκελο σε GitHub repository
2. vercel.com → New Project → import το repo
3. Στα Environment Variables βάλε `DATABASE_URL` και `JWT_SECRET`
4. Deploy
5. Μετά το πρώτο deploy, τρέξε μία φορά τοπικά (με το production `DATABASE_URL` στο `.env`):
   ```bash
   npm run db:deploy
   npm run db:seed
   ```

Η εφαρμογή είναι responsive — σε κινητό λειτουργεί σαν κανονική εφαρμογή μέσα από τον
browser, οι υπάλληλοι μπορούν να προσθέσουν το site στην αρχική οθόνη τους
(«Προσθήκη στην αρχική οθόνη») ώστε να ανοίγει σαν app.

## 5. Επόμενα βήματα (προαιρετικά)

- **Ειδοποιήσεις email** όταν εγκρίνεται/απορρίπτεται αίτηση (π.χ. με Resend)
- **Τμήματα με ξεχωριστό ελάχιστο προσωπικού** αντί για ένα κοινό όριο
- **Πολλαπλοί τύποι άδειας** (κανονική, αναρρωτική, άδεια χωρίς αποδοχές) με ξεχωριστά υπόλοιπα
- **Ιστορικό προσαρμογών** ορατό στον υπάλληλο (η βάση ήδη το κρατάει στο `BalanceAdjustment`)
- **Ρόλος «Προϊστάμενος τμήματος»** αν χρειάζεται εγκρίσεις σε επίπεδο τμήματος, όχι μόνο κεντρικά
